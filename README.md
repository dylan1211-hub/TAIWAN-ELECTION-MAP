# TAIWAN ELECTION MAP

以互動式地圖探索臺灣歷屆選舉結果，將選舉資料與行政區空間資訊整合呈現。

## 網站

url開啟 TAIWAN ELECTION MAPhttps://dylan1211-hub.github.io/TAIWAN-ELECTION-MAP/

## 目前功能

- 總統副總統歷屆選舉地圖（1996–2024）
- 縣市長歷屆選舉地圖
- 鄉鎮市區層級選舉結果
- 候選人得票數與得票率
- 政黨得票率與歷屆趨勢
- 歷屆政黨執政席次變化
- 互動式臺灣行政區地圖
- 桌面與行動裝置支援

## 資料來源

選舉資料主要整理自 **中央選舉委員會公開選舉資料**。

url中央選舉委員會選舉資料庫https://db.cec.gov.tw/

網站會針對不同年度的資料進行欄位整理、候選人資料標準化及行政區名稱對齊，再以統一格式呈現。

不同選舉年度的行政區與選舉制度可能有所不同，因此網站上的資料呈現方式會依當年度資料結構進行整理。

## 技術

本網站使用：

- HTML / CSS / JavaScript
- D3.js
- ECharts
- TopoJSON
- Taiwan Atlas 行政區圖資
- GitHub Pages

本專案為非官方的選舉資料視覺化網站，主要用途為資料查詢、研究與教育。

選舉資料內容請以中央選舉委員會公布的官方資料為準。

若發現資料疑義、行政區對應問題或網站功能異常，歡迎提出 Issue。
